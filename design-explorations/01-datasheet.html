The deck is the artifact
it teaches.

This talk argues that engineers should write specifications before they write code. So the slides are set as a specification: a metadata rail down the left edge, hairline rules instead of boxes, and every field labelled in monospace out in the gutter. Nothing is decorated — structure is the only ornament.

Best for
A room of engineers who read RFCs. Reads as precise, unhurried, non-salesy.
Costs you
Unforgiving. Every misalignment shows. Content must be tightly edited.
Risk taken
Almost no filled containers. The whole deck rests on rules and alignment.

Vibe Coding vs. Agentic Engineering

Vibe Coding"Real quick, let me just …" Agentic Engineering"Before I touch a key …"
InputA gut-feel promptA clear specification
ContextWhatever the model happens to knowMemory, Skills, MCP
Workflow"Let's see what comes out"Plan → Code → Review
ReviewAccept the suggestionChecked diff by diff
