# Orphan spec

A folder holding a spec and nothing else is indistinguishable from abandoned
work. Either the feature carries its four artifacts, or the spec says why not —
`fast_path: true` for the granted spec+verification path, or
`incomplete: <why>` while it is in flight.

Expected: `[incomplete-feature] missing plan, tasks, verification`.
